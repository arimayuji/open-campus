Logistic regression

Predict the probability of a yes-or-no outcome by passing a through the .

In plain words

Think about whether you wear a coat. When it is very cold the answer is always yes, when it is very warm it is never, and in between you are not sure. Logistic regression draws exactly that: a smooth curve from “surely yes” through “not sure” to “surely no”, instead of one hard line.

Step by step

1A hard boundary hides what we do not know

A such as the perceptron only says which side of a line a point is on. Real data is messier: some regions are uncertain, and we would like the model to say so, as a .

2Turn the score into a smooth curve

The (or logistic function) takes any score z and returns a value between 0 and 1. Very low scores give close to 0, very high scores give close to 1.

σ(z) = 1 / (1 + e^−z)
g(x) = σ(θᵀx + θ₀)
3Find the 50-50 line

Where θᵀx + θ₀ equals 0, the model gives exactly 1/2. That is a line, the between the two predictions. This is the same family of linear classifiers as before, now with a confidence attached.

4Score the guesses

Good weights give high probability to what really happened. We take the log, which keeps the same best weights, and then the negative, so that lower is better. That is the .

loss = −log( probability given to the true label )
5Walk downhill

nudges the weights to raise the probability of what happened, again and again, until the gradient is very small and there is nowhere left to go. This loss is convex, so descent gets good results.

6Do not be too sure

Huge weights make every probability more extreme, which lowers the loss but claims more confidence than the data can justify. A penalizes that.
