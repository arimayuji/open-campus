# Open Campus brand

## Logo
`assets/logo-mark.svg`: an open arch (a campus gate with one leg open) and a thin neural branch that bends inside it and reaches a coral node at the opening. The arch is "open", the branch is plasticity, the node is a connection made. On dark backgrounds swap the ink strokes for the paper colour.

## Palette
Values are `oklch` in `prototype/lesson/tokens.css`; hex is approximate.

## Rules
- Coral marks only two things: mastered concepts and the connection in the logo. Never a banner, never a button fill.
- Buttons are ink on paper; one filled primary per screen.
- No second accent hue. Mastery is shown by shape (filled, outlined, dashed), not by extra colours.
- Type: General Sans for text and headings, Geist Mono for formulas and figures.
- Light is the default, dark is a full re-derivation of the tokens, not an inversion.
- All UI copy in English.
